# Starbucks Sales & Business Performance Analytics

An end-to-end sales analytics project built using **Microsoft Excel, Power Query, Power Pivot, and DAX**.

This project explores sales performance, customer behaviour, product profitability, and store performance through interactive dashboards and business insights.

## Project Overview

The objective of this project was to transform raw sales data into meaningful business information and understand the factors influencing overall business performance.

I worked through the complete analytics workflow, starting with data cleaning and transformation, followed by data modelling, DAX calculations, KPI development, dashboard creation, and business analysis.

> **Note:** This is an independent practice project built using a Starbucks-style synthetic dataset. It is not an official Starbucks project and is not affiliated with Starbucks Corporation.

## Tools & Technologies

- **Microsoft Excel** – Data analysis and dashboard development
- **Power Query** – Data cleaning and transformation
- **Power Pivot** – Data modelling and table relationships
- **DAX** – Calculated columns, measures, and business KPIs
- **Pivot Tables & Pivot Charts** – Data analysis and visualization

## Project Workflow

1. **Data Preparation:** Cleaned and transformed raw datasets using Power Query.
2. **Data Modelling:** Created relationships between customer, order, product, store, region, target, and calendar data using Power Pivot.
3. **DAX Calculations:** Developed measures for sales, profit, margins, order metrics, and growth indicators.
4. **Dashboard Development:** Built interactive dashboards using KPI cards, charts, and slicers.
5. **Business Analysis:** Identified performance trends and translated findings into business insights.

## Key Business Findings

- North was the highest-performing region, while East recorded the lowest sales.
- Merchandise and Food were the leading sales categories compared with Beverages.
- UPI was the leading payment method by sales.
- Annual sales declined from approximately ₹73.56 lakh in 2024 to ₹70.73 lakh in 2025.
- Q4 was the strongest quarter in 2024, while Q2 was the strongest quarter in 2025.
- Monthly sales showed fluctuations rather than a consistent upward trend.

**Data consideration:** 2026 data covers January to October, so it should not be directly compared with full-year figures.
